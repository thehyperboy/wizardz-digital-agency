# WizardZ — Digital Marketing & Growth Engineering Website

A high-performance, responsive web application inspired by the **WizardZ / Positivus** neo-brutalist digital agency design language.

## 🚀 Key Features & Upgrades

1. **Faithful Visual Re-creation & Design System**:
   - **Signature Highlighter Badge System**: Distinctive lime green (`#B9FF66`) and dark onyx (`#191A23`) section badges and title pills.
   - **Grotesque & Geometric Typography**: Curated pairing of Google Fonts **Space Grotesk** (display & headers) and **Plus Jakarta Sans** (legible body copy).
   - **High-Contrast Alternating Cards**: 45px rounded brutalist cards with thick borders, offset box-shadows, and micro-hover lifts.

2. **Upgraded Interactive Enhancements**:
   - **Hero 3D Tilt Parallax Megaphone**: Central vector megaphone responds dynamically to cursor coordinates, complete with orbiting concentric soundwave rings and floating badges (Heart, Share, Play, Map Pin, Sparkle Stars).
   - **Interactive Mascot Character**: In the *"Let's make things happen"* banner, the cute character's pupils track user cursor movement across the screen.
   - **Interactive ROI & Growth Simulator**: Real-time interactive sliders for Monthly Visitors, Conversion Rate, and Average Order Value calculating instant projected monthly revenue lift and ROAS.
   - **Deep-Dive Modals**:
     - Service Detail Drawer (deliverables breakdown, KPIs, scope roadmap).
     - Case Study Modal (in-depth metrics breakdown, challenge/solution architecture).
     - Consultation Scheduler (date and time slot booking simulation).
   - **Working Process Accordion**: Step-by-step 01 to 06 with smooth height transitions and active lime background highlighting.
   - **Client Logo Marquee**: Infinite smooth sliding ticker with Amazon, Dribbble, HubSpot, Notion, Netflix, Zoom.
   - **Testimonials Carousel**: Speech bubbles with neon borders, customer ratings, autoplay, and manual dot/arrow controls.
   - **Interactive Contact Form & Proposal Generator**: Radio mode selector ("Say Hi" vs "Get a Quote"), service checkboxes, live validation, celebratory confetti explosion, and toast notifications.

## 🛠️ Tech Stack

- **HTML5 & Vanilla CSS**: Pure CSS custom properties, responsive grid/flexbox, zero heavy framework lock-in.
- **Modern JavaScript**: Modular interactive scripts with event handling, DOM manipulation, and math algorithms for cursor tracking and ROI projections.
- **Vite 6**: Instant HMR and lightning-fast asset pipeline.
- **Canvas-Confetti**: Interactive reward animations upon booking or submitting a proposal.

## 💻 Running Locally

```bash
# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

The application is running live at `http://127.0.0.1:5173/`.
